# Kersen X (kersenx.ilman.corp)

Game Launcher & Display Resolution Engine berbasis Shizuku resmi (Standar Pixels) yang dibangun 1:1 dari fitur Axeron, bebas dari bug Wireless Debugging, dilengkapi dengan **Mode X (ROG Performance)**, **Grafik MC (Potato Mode)**, dan **Per-Game Config**.

## Fitur Utama

1. **Space (Game Launcher & Per-App Config)**:
   - Deteksi otomatis game & aplikasi terpasang di HP.
   - **Per-Game Config**: Atur resolusi khusus, DPI, toggle Mode X, dan Grafik MC per game.
   - Tombol **PLAY** menerapkan settingan otomatis sebelum game dijalankan.

2. **Display Engine (Pixels Standard via Shizuku)**:
   - Pengubah resolusi (`wm size`) dan DPI (`wm density`) instan dan bebas bug.
   - Presets cepat: Native, 720p HD, dan **Grafik MC**.
   - Input custom resolusi dan tombol **Reset ke Default**.

3. **Tweak Khusus**:
   - **🎮 Grafik MC (Potato Mode)**: Memaksa downscaling tekstur dan resolusi 50% sehingga grafis 3D in-game menjadi kotak-kotak rata / flat ala Minecraft, mendongkrak performa dan kestabilan FPS (60-120 FPS).
   - **🔥 Mode X (ROG Performance)**: Memaksa 4x MSAA, mematikan HW Overlays (render penuh via GPU), dan memangkas proses background.
   - **⚡ Quick Boost (Memory Loosener)**: Membersihkan cache RAM dan memori proses.

4. **In-Game Corner Panel & Tools Melayang**:
   - Floating handle di sudut layar saat bermain game.
   - Custom Crosshair bidik presisi.
   - Real-time Session Monitor (FPS & RAM HUD).
   - HW Touch Enhancer (respon sentuh cepat).

5. **Vortex Status**:
   - Monitoring status Shizuku secara real-time.
   - Kartu profil developer & tautan media sosial.

## Cara Build Menjadi APK (Mudah Tanpa PC)

1. Unduh file `Kersen_X.zip` dan ekstrak di HP Anda.
2. Buat repository baru di akun GitHub Anda (lewat browser HP).
3. Upload seluruh file proyek ke repository tersebut.
4. Buka tab **Actions** di GitHub, proses build akan berjalan otomatis (~2-3 menit).
5. Unduh file APK siap pakai dari bagian **Artifacts**.
